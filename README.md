# Traffic Rush Casino (DEMO – εικονικά ευρώ)

8 παιχνίδια, λογαριασμοί παικτών, ήχοι, provably fair RNG. Παίζεται με **εικονικά ευρώ (demo)**, χωρίς πραγματικές συναλλαγές.
Θέλει **Node.js 18+** (https://nodejs.org → LTS). Καμία εξάρτηση, δεν χρειάζεται `npm install`.

## Υπόλοιπο και πονταρίσματα
- Κάθε νέος παίκτης ξεκινά με **100 €** (εικονικά). Μπόνους **50 €** κάθε 24 ώρες.
- Ελάχιστο ποντάρισμα **0,20 €**, γρήγορα κουμπιά 0,20 · 0,50 · 1 · 5 · 10 · 25 · Max. Μέγιστο 1.000 € ανά ποντάρισμα.
- Οι κερδισμένες αποδόσεις στρογγυλοποιούνται προς τα κάτω στο λεπτό, οπότε στα πολύ μικρά ποσά το πλεονέκτημα του καζίνο είναι ελάχιστα μεγαλύτερο.

## Υπεύθυνο παιχνίδι
Στο Προφίλ υπάρχουν **όρια παιχνιδιού**: όριο απωλειών ανά συνεδρία και υπενθύμιση χρόνου (προεπιλογή 30 λεπτά). Στη γραμμή DEMO φαίνεται πάντα η διάρκεια και το αποτέλεσμα της συνεδρίας.

## Εκκίνηση
- Windows: διπλό κλικ στο **start.bat** · Mac: διπλό κλικ στο **start.command**
- ή από τερματικό: `node server.js` (για κινητό: `HOST=0.0.0.0 node server.js`)

## Στο κινητό
1. Ο υπολογιστής και το κινητό πρέπει να είναι στο ίδιο Wi-Fi.
2. Τρέξε το start.bat / start.command. Στο μαύρο παράθυρο θα δεις γραμμή «On your phone (same Wi-Fi): http://192.168.x.x:3000».
3. Άνοιξε αυτή τη διεύθυνση στον browser του κινητού.
4. Για εικονίδιο στην αρχική οθόνη: iPhone → Κοινοποίηση → «Προσθήκη στην αρχική οθόνη»· Android → μενού ⋮ → «Προσθήκη στην αρχική οθόνη».
Αν τα Windows ρωτήσουν για Firewall, πάτα «Allow access».

## Online (για να παίζεις από παντού)
Έχει `Dockerfile` και `render.yaml` για hosting (π.χ. Render, Railway, Fly.io). Χρειάζεται δίσκος για το `/data/db.json`.
Το site πρέπει να είναι πίσω από HTTPS (το cookie γίνεται αυτόματα Secure).

## Αρχεία
`server.js` (λογαριασμοί, πορτοφόλι, API) · `lib/games.js` (λογική/πιθανότητες, μόνο server) · `lib/rng.js` (provably fair) · `public/` (frontend) · `data/db.json` (δημιουργείται αυτόματα).

## Ασφάλεια
Κωδικοί με scrypt + salt, cookie HttpOnly/SameSite=Strict, όριο αποτυχημένων συνδέσεων, υπόλοιπο και κλήρωση μόνο στον server.
Τα προσωπικά στοιχεία μπαίνουν σε αρχείο JSON χωρίς κρυπτογράφηση.

## Πριν από πραγματικά χρήματα
Δεν είναι έτοιμο για πραγματικά χρήματα. Χρειάζονται άδεια τυχερών παιχνιδιών (στην Ελλάδα ΕΕΕΠ), KYC, πληρωμές, κανονική βάση, HTTPS και πιστοποίηση RNG.

## Δημοσίευση στο Render (για το κινητό)
1. Ανέβασε το φάκελο σε ένα GitHub repository (new repository → upload files).
2. render.com → New → Web Service → σύνδεση με το repo → Runtime: Docker → Instance type: Free → Create.
3. Όταν τελειώσει, ανοίγεις τον σύνδεσμο `https://….onrender.com` στο κινητό και κάνεις «Προσθήκη στην αρχική οθόνη».
Σημ.: το δωρεάν πλάνο «κοιμάται» μετά από αδράνεια (το πρώτο άνοιγμα αργεί ~1 λεπτό) και δεν έχει μόνιμο δίσκο.
